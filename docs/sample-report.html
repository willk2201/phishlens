Filesamples/02_account_suspended.eml
FromNorthwind Bank Security <security@n0rthwind-bank.example>
SubjectURGENT: Your account has been suspended
Likely phishingrisk 100/100

highDMARC fail

The visible From address (n0rthwind-bank.example) is not backed by a passing SPF or DKIM check. This is the strongest sign the sender is being impersonated.

Seen: dmarc=fail

highLink text hides a different destination

The link says 'www.northwind-bank.example' but actually goes to '203.0.113.50'. Hovering over a link (or long-pressing on a phone) shows its real destination.

Seen: text=hxxps://www[.]northwind-bank[.]example/secure href=hxxp://203[.]0[.]113[.]50/northwind/login.php

highLink points to a raw IP address

Legitimate organisations link to their domain name, not a bare server address. This usually means a hastily set-up or compromised server.

Seen: hxxp://203[.]0[.]113[.]50/northwind/login.php

highLink to a look-alike domain

'northwind-bank.example.account-verify.example' imitates 'northwind-bank.example'. Fake login pages are hosted on domains like this to collect passwords.

Seen: hxxps://northwind-bank[.]example[.]account-verify[.]example/login

highSender domain imitates northwind-bank.example

The email comes from 'n0rthwind-bank.example', which is designed to look like 'northwind-bank.example' at a glance (swapped or extra characters, or the real name used as part of a different domain).

Seen: security@n0rthwind-bank.example

highDisplay name claims to be Northwind Bank

The name shown is 'Northwind Bank Security', but the real address is 'security@n0rthwind-bank.example', which does not belong to northwind-bank.example. Most email apps show only the name, hiding the real address.

Seen: Northwind Bank Security <security@n0rthwind-bank.example>

highReplies go to a different domain

The email is from 'n0rthwind-bank.example', but pressing Reply sends your answer to 'northwind.help@freemail.example'. Scammers do this so the conversation reaches them, not the real organisation.

Seen: Reply-To: northwind.help@freemail.example

mediumSPF fail

The email was sent from a server that n0rthwind-bank.example explicitly does not authorise, so the sender address is probably forged.

Seen: spf=fail

mediumAsks for passwords or personal details

Real organisations never ask you to confirm a password or card details by email.

Seen: "verify your identity"

lowDKIM none

The email carries no digital signature from the sender's domain.

Seen: dkim=none

lowUrgent or threatening language

Creates time pressure so you act before thinking it through.

Seen: "within 24 hours", "URGENT", "account has been suspended", "unusual sign-in"

infoGeneric greeting

Mass phishing doesn't know your name. On its own this is common in legitimate newsletters too.

Seen: "Dear Customer"

Filesamples/03_invoice_attachment.eml
FromAccounts Payable <billing@fastpay-invoices.example>
SubjectFinal notice: overdue invoice INV-20931
Likely phishingrisk 77/100

highDisguised file extension

'Invoice_INV-20931.pdf.exe' pretends to be a .pdf file but is really .exe. Windows hides known extensions by default, so it shows as 'Invoice_INV-20931.pdf'.

Seen: Invoice_INV-20931.pdf.exe

mediumHTML attachment

An attached web page opens locally in your browser, often as a fake sign-in form, and avoids the scanners that check links.

Seen: Remittance_Form.html

lowDMARC none

fastpay-invoices.example publishes no DMARC policy, so receiving servers have no instruction to reject forged email that claims to be from it.

Seen: dmarc=none

lowSPF softfail

The email was sent from a server fastpay-invoices.example does not list as authorised. Weaker than a hard fail, but still a warning sign.

Seen: spf=softfail

lowUrgent or threatening language

Creates time pressure so you act before thinking it through.

Seen: "immediately", "Final notice", "legal action"
